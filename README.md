# Pogo Assistant

Public Android APK downloads and release notes. Application source is maintained separately.

## Download

Get the latest signed APK from [Releases](https://github.com/zhangke0203/pogo-assistant-releases/releases/latest), expand **Assets**, and download the `.apk` file. Android 10 or newer is required.

Pogo Assistant provides on-device Pokémon GO Showcase estimates, an optional Back overlay, and a Poké Lids travel map with Pokémon filters, nearby sorting and lid-image previews. Scanning requires Android screen-capture consent and overlay permission; it does not automate Pokémon GO. Poké Lids uses public map data and OpenStreetMap tiles; location is optional.

## Installation and updates

The APK is signed with the permanent Pogo Assistant key. It can update recent permanent-key installations without uninstalling. Older temporary-key installations require a one-time uninstall/reinstall, which removes their local settings and history.

Certificate SHA-256:
`472a6e48c227ce2996b77666e7d2e7d6fe67b3a7b4b48eb13ee68ae084708f9a`

Each release includes an APK SHA-256 checksum. No keystore, signing password, instrumentation APK or private reference media belongs in this repository.

Map/location behavior and Showcase estimates should be checked on your device; automated build checks do not establish physical-device reliability or in-game scoring accuracy.
